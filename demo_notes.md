# Demo Notes

## Local Demo

1. Run `npm start`.
2. Open `http://localhost:4173`.
3. Click `Run Scan`.
4. Add a custom HTTPS Solana RPC endpoint if available.
5. Copy the generated Markdown report.

## Suggested Screenshot

Capture the page after a successful scan, showing:

- healthy endpoint count
- median latency
- sorted endpoint cards
- report export area

## Suggested GitHub Description

Browser UI and local proxy for comparing Solana RPC endpoint health, slot freshness, and latency.
